- Run:
  - pip install -r requirements.txt
  - jupyter notebook notebooks/FoodHub_Analysis.ipynb

Analysis highlights
- Use groupby and aggregation to find top restaurants by orders and revenue.
- Visualize delivery times distribution and identify slow zones.
- Segment customers by order frequency and average spend to propose retention actions.
